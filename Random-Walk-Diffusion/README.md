# Random Walk and Diffusion

## Overview

This project simulates a two-dimensional random walk and verifies the diffusion law using statistical analysis.

## Physics Background

Random walks are used to model:

- Brownian motion
- Diffusion
- Particle transport
- Stochastic processes

A particle starts at the origin and randomly moves:

- Up
- Down
- Left
- Right

at each time step.

## Theory

For a random walk,

<r²> ∝ t

where:

- r² = squared distance from origin
- t = number of steps

This relationship is known as the diffusion law.
