# N-Body Gravitational Simulation

## Overview

This project simulates planetary motion using Newtonian gravity and numerical integration.

The first version models Earth's orbit around the Sun and demonstrates how gravitational forces govern orbital motion.

---

## Physics Background

Newton's Law of Gravitation:

F = G(m₁m₂)/r²

The resulting acceleration determines the trajectory of celestial bodies.

---

## Methodology

1. Define initial positions and velocities.
2. Compute gravitational acceleration.
3. Update velocity and position.
4. Track orbital motion over time.
5. Visualize the resulting trajectory.
