# Gravitational Wave Analysis

## Overview

This project explores gravitational wave signals through numerical simulation and frequency-domain analysis. A gravitational-wave-inspired chirp signal is generated and analyzed using Fourier Transform techniques.

---

## Scientific Background

Gravitational waves are ripples in spacetime predicted by Einstein's General Theory of Relativity.

They are generated by:

- Binary Black Hole Mergers
- Binary Neutron Star Mergers
- Compact Binary Systems

As the objects spiral inward, both the frequency and amplitude of the emitted gravitational waves increase, producing a characteristic chirp signal.

## Methodology

1. Generate a chirp waveform with increasing frequency.
2. Visualize the waveform in the time domain.
3. Apply the Fast Fourier Transform (FFT).
4. Analyze the resulting frequency spectrum.
